## RESEARCH A NEW LANGUAGE

Haskell is a general-purpose, statically typed, functional programming language, used on the server-side of internet applications, named after Haskel B. Curry. It utilizes functions and algebraic data types offering concurrency and safety. The GHC is the de-facto compiler for the language. “Lazy” is a key feature of Haskell because functions do not evaluate their argument.

I've found that Haskell is a fascinating language because it is purely functional and statically typed, making it vastly different from the languages we usually start learning programming with. It is primarily used for building high-assurance software, complex data manipulation, parsing, and concurrent programming, as its strict mathematical foundation ensures that code is highly predictable and largely free of side effects. Because of this reliability, 

Haskell is heavily used by academic researchers exploring computer science theory, as well as by industries where a single bug could be catastrophic. For instance, tech giants like Meta use it to power robust anti-spam systems, aerospace companies use it for systems verification, and major financial institutions like Standard Chartered rely on it to process secure, large-scale transactions safely.

When it comes to actually learning Haskell, the most highly recommended starting point is the book Learn You a Haskell for Great Good!; it is incredibly useful because it uses humor and fun illustrations to break down notoriously difficult concepts into digestible, beginner-friendly lessons. Another essential tool is Hoogle, a unique Haskell API search engine. Hoogle is an absolute lifesaver because it allows you to search not just by function name, but by type signature, meaning if you know what data types you are putting in and what you want to get out, it will find the exact function you need to do the job. 

Finally, the official Haskell Wiki provides a wealth of community-driven guides that are perfect for bridging the gap between beginner exercises and real-world application development.

## WRITE A USER STORY

As a frequent traveler who uses the Trip Advisor app, I want to receive personalized destination and activity recommendations based on my past searches and saved locations, so that I can easily discover new vacation spots without spending hours researching from scratch.

Three acceptance criteria:

1\. Data Integration: By evaluating the last six months of the user's "Saved" spots and search records, the system is required to produce a minimum of five unique destination suggestions.

2\. Context Information: A label to clarify the reasoning behind the prompt on every recommendation, such as "Similar to your search for ski resorts" or "Because you saved hotels in Maui.

3\. Refresh and Dismissal: Users must have the option to reject a suggestion by selecting a "Not Interested" or "X" button; doing so should prompt an immediate replacement with a different recommendation and a corresponding adjustment to the user's preference profile.
